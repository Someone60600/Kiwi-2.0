# KIWI – Keep It Within Income

## Project Overview
KIWI is a simple, student-friendly expense-tracking system designed to help students monitor their spending, stay within budget and build budgeting discipline. The app allows students to set a monthly allowance or income, log and categorise daily expenses, view visual summaries (daily/weekly/monthly), and receive alerts when they approach their budget limit.

## Problem Statement
Many students struggle with tracking their daily small expenses and often run out of money before the end of the month. KIWI addresses this issue by giving students a clear, easy-to-use platform where they can see how much they spend and how much they can save.

## Key Features (Planned)
- Set monthly/weekly budget  
- Add an expense with date, amount and category  
- Dashboard with visuals: total spent, budget remaining  
- Alerts when spending crosses certain limits  
- Budget health indicator (Green → Yellow → Red)  
- Smart suggestions based on past spending  
- Savings streaks to encourage consistent budgeting

## Tech Stack
- Frontend: HTML, CSS, JavaScript (or Flutter mobile app)  
- Backend: Firebase (Authentication + Firestore) or Node.js  
- Database: Firestore / MongoDB  
- Charts: Chart.js or D3.js
